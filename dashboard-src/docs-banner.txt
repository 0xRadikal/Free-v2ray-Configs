  WHY THERE IS AN EXPLICIT </head> IN A MINIFIED FILE
  ---------------------------------------------------
  Parcel drops optional tags. An HTML5 parser does not mind - it infers the
  head element, and a spec-exact parser confirms the metadata lands there.
  Google's Search Console ownership checker does mind: with no literal <head>
  in the markup it replied "Your meta tag is not in the <head> section of your
  home page" and refused to verify, even though the tag was, by the standard,
  in the head. So the source writes <head id="head"> - an optional tag keeps
  its start tag once it carries an attribute, which is also why <html lang=en>
  survives - and /dashboard-src/make-docs.mjs puts the end tag back. Removing
  either would cost ownership of the Search Console property.
